# Resources for the CoAfina 2026 Hackathon

Tools and resources for hosting, analyzing, visualizing and sharing your project. Check each service’s current free-tier conditions before using it.

## Web Hosting and Cloud
- [Infomaniak](https://www.infomaniak.com/en): Hosting and cloud services.
- [Proton](https://proton.me/): Secure email, calendar and file storage.
- [GitHub Pages](https://pages.github.com/): Website hosting for your GitHub repositories.
- [Netlify](https://www.netlify.com/): Deploy modern web projects.
- [GitLab](https://gitlab.com/): A DevOps platform for developers.

## Interactive Computing and Notebooks
- [Jupyter](https://jupyter.org/): Open-source software for interactive computing.
- [PAWS (Wikimedia)](https://wikitech.wikimedia.org/wiki/PAWS): Jupyter notebooks for Wikimedia.
- [Google Colab](https://colab.google/): Cloud-hosted Jupyter notebooks.
- [NBViewer](https://nbviewer.org/): View Jupyter notebooks online.
- [MyBinder](https://mybinder.org/): Launch interactive notebook environments.

## Data Visualization and Dashboards
- [Streamlit](https://streamlit.io/#install): Turn Python scripts into interactive apps.
- [Dash (Plotly)](https://dash.plotly.com/): Build dashboards with Python.
- [Panel (HoloViz)](https://panel.holoviz.org/): Build Python apps and dashboards.
- [Google Charts](https://developers.google.com/chart): Tools for charts and data visualization.
- [D3.js](https://d3js.org/): A JavaScript library for interactive data visualization.

## AI and Machine Learning
- [OpenAI](https://openai.com/): AI research and deployment tools.
- [Mistral AI](https://mistral.ai/): AI tools and models.
- [Hugging Face](https://huggingface.co/): Open-source machine learning tools and models.
- [Ollama](https://ollama.com/): Run AI models locally.
- [Gradio](https://www.gradio.app/): Build and share machine learning interfaces.

## Application Development and Deployment
- [Anvil](https://anvil.works/): Build web apps with Python.
- [Docker](https://www.docker.com/): Build, share and run applications in containers.
- [DockerHub](https://hub.docker.com/): Share and discover container images.

## Educational Resources and Examples
- [Wikimedia](https://www.wikimedia.org/): Free knowledge projects.
- [Zenodo](https://zenodo.org/): A research repository.
- [Academic Torrents](https://academictorrents.com/): Share research datasets.
- [GitHub Government](https://github.com/github/government.github.com): Open-source projects in government.
- [Square Open Source](https://github.com/square/square.github.io): Open-source projects from Square.
- [Netflix Open Source](https://netflix.github.io/): Open-source projects from Netflix.

## APIs and Integration

- [X API Rules and Policies](https://help.x.com/en/rules-and-policies/x-api): Guidelines for using the X API.

- [15 Free Hosting Options for Front-End Developers](https://blog.bitsrc.io/15-free-hosting-for-front-end-developers-9224bc34e14a): A guide to free hosting options.
