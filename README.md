# Recursos para el Hackathon CoAfina 2026

¡Hola, hackers! 🎉 Hemos reunido una lista de recursos y herramientas que harán tu vida más fácil durante el hackathon.

Aquí encontrarás de todo: desde plataformas para alojar tu proyecto hasta herramientas de visualización de datos y APIs de IA. ¡Explora los enlaces y empieza a crear algo increíble!

---

## 🌐 Alojamiento Web y Nube
- [Infomaniak](https://www.infomaniak.com/en): Soluciones pro para hosting y nube.
- [Proton](https://proton.me/): Email seguro, calendario y almacenamiento de archivos.
- [GitHub Pages](https://pages.github.com/): Alojamiento gratuito para tus repos en GitHub.
- [Netlify](https://www.netlify.com/): Despliega proyectos web modernos con facilidad.
- [GitLab](https://gitlab.com/): Plataforma DevOps para desarrolladores.
- [Render](https://render.com/articles/should-i-use-render): Nube para desplegar apps, bases de datos y sitios estáticos; esta guía explica para quién sirve y sus límites.
- [Streamlit Community Cloud](https://streamlit.io/cloud): Publica apps de Streamlit desde un repositorio de GitHub.
- [Hugging Face Spaces](https://huggingface.co/spaces): Aloja demos de Gradio o Streamlit.

# Mantenimiento del sitio

Consulta [README-pages.md](README-pages.md) para publicar el sitio, actualizar fechas y enlaces, y añadir retos.

## Abrir o cerrar las convocatorias

Las convocatorias de retos y de hackers se abren y se cierran en [`convocatorias.json`](convocatorias.json):

```json
{ "retos": false, "hackers": false }
```

Cambia `false` por `true` para abrir una convocatoria, o `true` por `false` para cerrarla. Guarda el cambio («Commit changes») y el sitio se actualiza en uno o dos minutos, en español y en inglés. Los patrocinios están siempre abiertos.

El mismo archivo tiene `retosVisiblesDesde`, la fecha y hora (en UTC) desde la que el sitio muestra los retos; antes muestra un aviso.

La guía completa, con lo que cambia en cada parte del sitio, está en [README-pages.md](README-pages.md#el-interruptor-de-las-convocatorias).
